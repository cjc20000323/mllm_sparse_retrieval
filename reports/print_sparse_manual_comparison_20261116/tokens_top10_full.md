## 类别与读取规则

| 类别 | 模态 | 配置与记录范围 |
|---|---|---|
| SSR | text | `sparse_manual=false`；实际保留的原文候选 Top-10 |
| PTT | text | `sparse_manual=true`；单一 Summary 提示的全词表 Top-10 |
| PTT | image | `sparse_manual=true`；单一 Summary 提示的全词表 Top-10 |
| MPP | text | 已选 J、A、C、B、D、I 六个视角，每个视角的全词表 Top-10 |
| MPP | image | 已选 J、A、C、B、D、I 六个视角，每个视角的全词表 Top-10 |

- 排名与权重直接取自日志，不重新排序、归一化或量化。原始权重类型为 `log1p_relu`，不是概率。
- token 用 JSON 字面量表示，以保留大小写、词首前缀、空白和词片段；token ID 为模型词表 ID。
- 列表中的零权重项也完整保留。SSR 原文候选不足十个时，按实际记录数量列出。
- 补全标记沿用既有规则：两种文本 Top-10 都有正权重，PTT 图像 Top-10 中缺失，MPP 图像至少一个视角 Top-10 中有正权重。
- 比较时只转为小写，保留 `"▁"` 前缀，不做词干化、同义词替换或词片段扩写；同一词项跨视角只计一次。
- 加粗表示该 token 对应既有补全词项且本行权重大于 0。MPP 文本中的加粗用于展示这些词项是否也出现，不增加原先的补全计数。
- “新增正权重稀疏维度”根据已保存的最终向量确认，区别于仅补回 Top-10 排名。完整向量不在本文展开。
